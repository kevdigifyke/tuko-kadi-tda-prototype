# KuraScope EOIS

**KuraScope — Election Observatory Intelligence System**

A Geospatial Election Intelligence and Observatory Platform for realtime election monitoring, anomaly detection, simulation, and operational visibility.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view KuraScope EOIS.

## Project Identity

KuraScope EOIS presents the application as an Election Observatory Intelligence System while preserving the existing observatory, telemetry, replay, scenario, analytics, agents, evidence, and results workflows.
